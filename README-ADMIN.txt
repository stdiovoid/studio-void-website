# STUDIO VOID Admin Panel — Preview Version

## فایل‌های این بسته
- `admin.html`
- `admin.css`
- `admin.js`

این‌ها فایل‌های جدید هستند و فایل‌های قبلی سایت را جایگزین نمی‌کنند. آن‌ها را در ریشه همان مخزن GitHub، کنار `index.html` قرار دهید.

پس از انتشار، پنل از این نشانی باز می‌شود:
`https://stdiovoid.github.io/studio-void-website/admin.html`

## محدودیت مهم
این نسخه یک پیش‌نمایش مدیریتی بدون رمز است. تغییرات با localStorage فقط در همان مرورگر و همان دستگاه ذخیره می‌شوند؛ هنوز روی سایت عمومی اعمال نمی‌شوند. چون پنل بدون ورود و محافظت است، اطلاعات محرمانه در آن قرار ندهید. در مرحله بعد باید دیتابیس، احراز هویت مدیر و API امن اضافه شود تا تغییرات برای همه بازدیدکنندگان منتشر شود.
