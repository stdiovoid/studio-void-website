# STUDIO VOID — Corporate Website (Starter)

A bilingual (Persian/English), responsive first-stage website for STUDIO VOID.

## Included
- Responsive landing page for mobile and desktop
- Persian RTL and English LTR language switch
- About, services, selected work and contact sections
- Official Telegram and Rubika links
- No build tools or package installation required

## Files
- `index.html` — page structure and content
- `styles.css` — visual design and responsive layout
- `script.js` — language switch and mobile navigation

## Publish with GitHub Pages
1. Create a new repository named `studio-void-website`.
2. Upload the contents of this folder to the repository root (not the ZIP file itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub will show the published website URL in the Pages section.

## Important next step
This package is the public-facing frontend only. It does **not** yet contain an admin login, database, form processing, or a secure content-management backend. Those require a separate backend setup (recommended: Supabase) and must be added before calling the site fully manageable or production-ready.
