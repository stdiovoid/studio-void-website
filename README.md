# STUDIO VOID Website

این نسخه با ساختار نسخه اولیه سازگار است و همچنان با GitHub Pages و بدون نصب ابزار یا فرایند build اجرا می‌شود.

## فایل‌ها
- `index.html`
- `styles.css`
- `script.js`

## انتشار
فایل‌ها را در ریشه همان مخزن GitHub قرار دهید. برای به‌روزرسانی سایت، فایل‌های هم‌نام قبلی را با نسخه‌های این بسته جایگزین کنید؛ نیازی به ساخت مخزن جدید یا تغییر تنظیمات GitHub Pages نیست.
