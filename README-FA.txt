بسته تکمیل سایت STUDIO VOID
=============================

محتویات:
- index.html / styles.css / script.js : سایت عمومی، فارسی و انگلیسی، دریافت پروژه‌ها و اطلاعیه‌ها از Supabase
- admin.html / admin.css / admin.js : پنل ورود مدیر و مدیریت CRUD
- config.js : آدرس Supabase و کلید عمومی Publishable
- admin-setup.sql : راه‌اندازی نقش مدیر و مجوزهای Data API

روش نصب:
1) از مخزن فعلی یک نسخه پشتیبان بگیر.
2) فایل‌های همین بسته را در ریشه مخزن جایگزین فایل‌های هم‌نام کن و config.js را هم اضافه کن.
3) در Supabase > Authentication > Users، برای ایمیل مدیر دعوت‌نامه بفرست و حساب را ایجاد/تأیید کن.
4) فایل admin-setup.sql را در SQL Editor پروژه Supabase اجرا کن.
5) مدیر یک بار از پنل خارج شود و دوباره وارد شود تا JWT جدید شامل app_metadata.role=admin باشد.
6) سایت و /admin.html را با HTTPS باز کن و تست کن.

مهم:
- هیچ رمز عبوری در فایل‌ها قرار نگرفته است.
- کلید Publishable برای مرورگر است؛ کلید service_role یا Secret را هرگز در سایت قرار نده.
- RLS باید فعال بماند. اسکریپت SQL مجوزهای نقش‌ها را می‌دهد اما جایگزین RLS policy نیست.
- فقط حسابی که app_metadata.role برابر admin داشته باشد اجازه پنل می‌گیرد.
- این بسته فایل‌های مخزن را خودکار منتشر نمی‌کند؛ باید خودت فایل‌ها را در مخزن جایگزین و commit کنی.
- اطلاعات قدیمی localStorage خودکار به دیتابیس منتقل نمی‌شوند؛ فایل‌های قبلی را پاک نکن تا در صورت نیاز بتوانیم داده‌ها را جداگانه مهاجرت دهیم.
- آدرس پنل: /admin.html
- کتابخانه Supabase از CDN بارگذاری می‌شود؛ برای اجرا اینترنت لازم است.
