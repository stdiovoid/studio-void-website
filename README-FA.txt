STUDIO VOID — بسته ارتقای سایت و پنل مدیریت

نصب:
1) از مخزن GitHub خود یک نسخه پشتیبان بگیرید.
2) فایل‌های داخل ZIP را در ریشه مخزن جایگزین فایل‌های هم‌نام کنید.
3) تغییرات را Commit کنید و چند دقیقه برای به‌روزرسانی GitHub Pages صبر کنید.
4) سایت: https://stdiovoid.github.io/studio-void-website/
5) پنل: https://stdiovoid.github.io/studio-void-website/admin.html

امکانات:
- نمایش پروژه‌ها با دسته‌بندی و فیلتر
- افزودن، ویرایش، حذف و جابه‌جایی پروژه‌ها
- اطلاعیه بالای صفحه اصلی
- مدیریت دسته‌بندی‌ها
- پشتیبان‌گیری و بازیابی JSON
- نمایش فارسی/انگلیسی پایه در عنوان و توضیحات پروژه

محدودیت مهم:
این نسخه آزمایشی است و داده‌ها را در localStorage همان مرورگر ذخیره می‌کند.
بنابراین پنل و سایت فقط در همان مرورگر/دستگاه داده مشترک دارند؛ تغییرات پنل برای بازدیدکنندگان دیگر منتشر نمی‌شود.
ورود مدیر، دیتابیس مشترک، آپلود واقعی تصویر و آمار بازدید واقعی هنوز پیاده‌سازی نشده‌اند.
برای انتشار عمومی و مدیریت امن باید در مرحله بعد دیتابیس و احراز هویت (مثلاً Supabase با RLS) متصل شود.
آمار بازدید در این نسخه ساختگی نیست و عمداً نمایش داده نمی‌شود.

برای تصاویر، فعلاً از آدرس مستقیم HTTPS استفاده کنید.
